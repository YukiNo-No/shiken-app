# 体外循環技術認定士 対策問題集

体外循環技術認定士試験の対策用クイズアプリです。全19章・390問を、分野別練習モードとランダム模擬試験モードで学習できます。

## 機能

### 分野別練習
- 章をタップすると、問題番号（1〜N）を選べます
- 「問1から通して解く」または好きな番号から順番に解答
- 1問ごとに正誤と解説をその場で表示します（正解でも解説を表示）

### ランダム / 模擬試験
- 出題数（20問 / 50問 / 100問 / 全問）を選択
- 出題範囲（全19章 or 特定の章）を選択
- 出題順はランダム
- 全問解答後にまとめて採点し、分野別の正答率内訳と全問の解説をまとめて表示します（正解でも解説を表示）

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドや依存ライブラリのインストールは不要です。

## 技術的な特徴

- 依存ライブラリなしの単一HTMLファイル（CSS・JavaScript・問題データすべて内包）
- 成績はブラウザのメモリ上でのみ集計され、どこにも保存されません
- スマートフォンでの利用を想定したレスポンシブデザイン

## GitHub Pagesでの公開方法

1. このリポジトリの `index.html` をリポジトリのルートに配置する
2. GitHubリポジトリの Settings → Pages で公開ブランチを設定する
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる
